Gestión de usuarios y asignación de roles

La configuración actual de Supabase concede SELECT a usuarios autenticados, pero no concede INSERT, UPDATE ni DELETE. Por seguridad, esta versión no simula cambios ni intenta modificar roles. Para habilitar altas, cambios y bajas hace falta crear funciones RPC seguras con validación del fundador y reglas específicas en la base de datos.
